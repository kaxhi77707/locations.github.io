Website folder GitHub par upload karein

Poora folder, images, CSS aur pages — ek commit mein.

Pehle website ki full ZIP extract karein. Phir woh folder select karein jiske andar seedha index.html aur wp-content hain. Folder structure waisa hi rahega.
Token khud banayein: GitHub par token banayein ↗. Sirf is repository ko select karein aur Contents: Read and write permission dein. Token kisi ko chat mein na bhejein. Yeh page token save nahi karta; requests seedha GitHub API ko jaati hain. Abhi folder select nahi hua.
Dhyan dein: Is uploader ko sirf trusted copy se kholein. Yeh selected branch par files add/replace karega; doosri existing files delete nahi karega. Browser window upload ke dauran khuli rakhein. GitHub Pages Settings mein branch main / (root) select honi chahiye.
